## Context

A client’s business rules live in legacy scripts written in a proprietary programming language. The scripts need maintaining and documenting now, and migrating later. Because the language is proprietary, general-purpose models can’t be trusted with it out of the box.

## What I did

I lead the agent’s design and delivery. A LangGraph dual-state dynamic workflow coordinates vLLM-served models with retrieval. EBNF grammars constrain every output to what the grammar allows, and PII filtering keeps personal information out. The agent writes documentation, extracts business rules, and prepares the code for migration.

<Note term="LangGraph">An open-source library for building agents as graphs of steps that share state.</Note>

<Note term="vLLM">An open-source engine for serving large language models.</Note>

<Note term="EBNF">Extended Backus–Naur form, a notation for grammars. A model constrained by a grammar can only produce output the grammar allows.</Note>

<Note term="PII">Personally identifiable information: data that identifies a person, such as a name or an email address.</Note>

## Outcome

Projected **50%** less manual work. In progress.

Client work, no public page.
